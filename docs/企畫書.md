> 依據《大王焼き.xlsx》製作，並補上實作時的設計判斷（標註 ★）。

## 1. 基本資訊

| 項目 | 內容 |
|---|---|
| 遊戲名稱 | 大王焼き（副標：リズム屋台／節奏熱炒遊戲） |
| 類型 | 單鍵節奏遊戲（參考《節奏天國》） |

## 2. 核心玩法

1. 食材從畫面左側或右側（隨機）以拋物線丟向鐵板中央的**判定框**。
2. ★ 每個食材都在落點**前 2 拍**丟出，並伴隨「咻～啵」提示音，四種食材的提示音高不同。玩家可以「先聽、再按」，這就是《節奏天國》的核心手感。
3. 食材落到判定框的瞬間按下按鈕，依時間誤差判定：

   | 判定 | 誤差 | 基本分 |
   |---|---|---|
   | GREAT | ±50ms | 300 |
   | NICE | ±90ms | 200 |
   | GOOD | ±130ms | 100 |
   | BAD | ±180ms，或沒按 | 0（連擊中斷） |

   ★ 另有連擊加分：每次命中加 `min(連擊數, 50) × 4` 分。

4. 判定成功後，食材變成處理完成的樣子，再隨機往左或右滑出畫面，並計入右上角的食材數量。
5. 四種食材各集滿 1 個，就自動合成**一份廣島燒**，獎勵 +1000 分，並播放演出（主角歡呼）。
6. ★ 沒有食材時按下按鈕只會揮空，不扣分，讓玩家可以放心跟著節拍按。

## 3. 食材與主角動作

| 食材 | 生食材圖 → 完成圖 | 主角動作 | 處理音效 |
|---|---|---|---|
| 炒麵 | 生麵 → 炒麵 | 鍋鏟翻炒 | 滋～（鐵板聲） |
| 高麗菜 | 整顆 → 切絲 | 拿刀切 | 咚咚（刀聲） |
| 煎餅 | 餅皮 → 淋醬餅皮 | 擠醬汁 | 噗啾 |
| 培根 | 整條 → 切塊煎香 | 拿刀切 | 咚咚 |

主角反應：

★ 判定框上同步有處理特效：切＝刀光閃過、炒＝食材在鐵板上翻一圈並冒火花、淋醬＝醬汁一筆一筆畫上去。

| 時機 | 姿勢 |
|---|---|
| 打擊成功（GREAT／NICE／GOOD） | ★ 做上表的處理動作並維持約 0.36 秒，往上探身讓工具露出鐵板；好壞由大字判定顯示 |
| 每 10 連擊 | 跳起握拳＋「10 COMBO!」 |
| SPEED UP 休息小節 | 雙手比讚 |
| BAD | 冒汗抓頭 |
| 完成廣島燒 | 張開雙手跳 |
| 主畫面 | 揮手 |

## 4. 節奏設計

- **速度**：每 8 小節加快一次，BPM 依序為 96 → 104 → 112 → 122 → 134 → 146。
- ★ **節奏型**：分 4 個難度等級，共 24 種。從單拍、二拍開始，逐步加入反拍（八分音符）和切分音。
- ★ **兩小節一組**：同一個節奏型連出兩次，第一次讓玩家聽，第二次就能抓到韻律（《節奏天國》的「示範→模仿」結構）。
- ★ **喘息小節**：每段的第 8 小節不丟食材，太鼓打過門（fill），畫面顯示「SPEED UP!」。
- ★ **食材分配**：用「袋子隨機」，每 4 個食材四種各出一次，避免同一種連續出現、遲遲湊不到廣島燒。

## 5. 音樂

★ 共 30 首樂曲、分三集各 10 首（風格與 BPM 見 README「樂曲」；VOL.3 每首有自己的打擊節奏型）。以下為 VOL.1 第 3 首「屋台ばやし」的編制：

全部在瀏覽器即時合成，不需要音檔：

| 樂器 | 加入時機 |
|---|---|
| 太鼓（ドン／カッ），每小節都有咚咚重拍 | 一開始 |
| 三味線主旋律（D 大調五聲音階，8 小節循環，可愛祭典風） | 一開始 |
| 貝斯 | 一開始 |
| 拍手 | 第 2 段起 |
| 鉦（チャンチキ） | 第 3 段起 |
| 篠笛（和三味線同一段旋律，高八度） | 第 5 段起 |

★ 隨著速度變快一層層加入樂器，越後面越熱鬧。

## 6. 畫面與 UI

| 位置 | 內容 |
|---|---|
| 左上 | SCORE、HISCORE（＝排行榜第 1 名）、TEMPO、進度條、COMBO |
| 右上 | 廣島燒成品數量（大，較顯眼）；四種食材數量（2×2 小圖示，增加時會跳動） |
| 中央 | 主角站在攤位裡；鐵板吧台在前景，上方的金色虛線框是判定框，會隨節拍跳動 |
| 下方 | 按鈕圖（按下時會有壓下動畫） |
| 右上角 | ⏸ 暫停鈕 |

- **主畫面**：主角揮手、「リズム屋台」標題帶、TAP TO START，右下角 ©Arc's Concept Game。
- **燈光效果**：燈籠光暈跟著節拍一起閃，加上火星粒子往上飄。
- **結算畫面**：顯示完成的廣島燒份數、分數、是否刷新紀錄、各判定次數、最大連擊。
- **節奏評價**：依「得分 ÷ 該曲滿分」蓋上 5 級印章並附逗趣評語（滿分 = 全 GREAT＋連擊不斷＋所有廣島燒）：
  特上 ≥90%「傳說的鐵板之神」／上 ≥75%「人氣排隊名攤」／並 ≥55%「認真的見習生」／見習 ≥35%「手忙腳亂的新人」／修行「鐵板上的災難」。門檻與文字在 `js/config.js` 的 `RATINGS`。
- ★ 切到其他分頁、視窗失去焦點、手機轉橫時會自動暫停。

## 8. 選單與功能（參考 Top_Race）

| 畫面 | 內容 |
|---|---|
| 開始畫面 | ★ 開場一開始的夜空（月亮、星星、遠處燈籠串）＋ TAP TO START／PRESS ANY KEY（依輸入裝置切換）；點一下無縫接進開場（這一下同時解除瀏覽器的音效限制，開場才有聲音） |
| 開場 | ★ 約 7.6 秒：野台從畫面下方緩緩升起，月亮與燈籠串以視差往上移（鏡頭往下帶）；同時夜空施放 8 發煙火（有升空哨音、爆炸聲與劈啪聲）→ 落地揚塵、燈籠一盞盞亮起 → 主角從右邊一蹦一跳走進野台 → 揮手「歡迎光臨！」（「いらっしゃいませ！」語音）→ 暖簾落下 → 淡入主選單（構圖相同、音樂不中斷）。演出中點畫面／按任意鍵立即跳到主選單 |
| 主選單 | 開始遊戲、操作說明、排行榜、設定、CREDIT；選單有背景音樂。第一次按「開始遊戲」會先進入新手教學 |
| 選擇樂曲 | ★ 30 首歌分三集（VOL.1～VOL.3 各 10 首，依星級由易到難；上下選曲〔手機上下滑動、PC 方向鍵／手把／滾輪〕，清單轉盤式捲動，左右切換 VOL），木牌卡片：歌名、副標・風格、BPM、星級（最多 5 星）、HISCORE；選中的歌自動試聽；右上角掛著「新手教學」木札（會發光、每隔幾秒晃一下）可隨時複習；進入時播放選曲語音，試聽在語音後才開始 |
| 新手教學 | 可以玩的練習（84 BPM 慢歌）：① 單拍＋時機提示圈 4 次 → ② 連續打 6 次 → ③ 做出 1 份廣島燒；達成後自動進下一步，完成卡片列出要訣。可暫停、略過（略過也算看過） |
| 操作說明 | 4 頁：遊戲規則、操作方式（顯示手把是否已連接）、判定與計分、食材圖鑑；手機可左右滑動換頁 |
| 設定 | 音樂音量、音效音量（0～5）；★ 判定校正（−200～+400ms，同時移動畫面與判定，讓看到、聽到、判定一致；並顯示上一局平均時間差）＋★ 自動校正（跟著「叩」聲點 16 下，取中位數量出耳機／藍牙延遲，一鍵套用）；手機震動 ON/OFF；★ 省電模式 ON/OFF（30 幀、低解析度、少特效）；語言（中文／日本語／English）；★ 安裝到主畫面（PWA 簡易教學，依裝置排序並標示「你的裝置」） |
| 排行榜 | 每首歌各自前 20 名（← → 切換樂曲；名次、姓名、廣島燒數、分數）；預設本機，可接 Firebase 變成全球排行 |
| CREDIT | 企劃：Arc Wang、大王KUNI；特別感謝：Kelvin Lo、Bubu Lin；廣島燒圖冒著熱騰騰的蒸氣 |
| 結算 | 成績統計；進前 20 名可輸入姓名登錄，之後跳到排行榜並以高亮顯示 |
| 暫停 | 繼續遊戲、重新開始、設定、回主選單 |

★ **暫停後繼續**：先依當下速度倒數 3 拍，倒數落在原本的拍點上，第 4 拍正好接回樂曲，玩家不會被打亂節奏。
