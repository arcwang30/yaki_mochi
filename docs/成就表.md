# 大王焼き リズム屋台：成就表

> 主選單「成就」按鈕目前是預留狀態（點進去顯示「準備中」）。本表是實作前的正式規格：共 **58 個成就**，分 11 類、4 個等級。
> 數字門檻依目前內容訂定：75 首（內建曲目 15 首＋VOL.1～VOL.6 各 10 首）、3 種難度、5 級評價、FC／AG 獎章、音感等級、商店商品。

## 1. 等級與遊戲幣獎勵

| 等級 | 數量 | 每個獎勵 | 小計 | 難度感 |
|---|---|---|---|---|
| 銅 | 16 | 20 | 320 | 正常玩就會拿到 |
| 銀 | 18 | 60 | 1,080 | 玩一陣子、稍微練習 |
| 金 | 16 | 150 | 2,400 | 需要投入與技術 |
| 白金 | 8 | 300 | 2,400 | 長期目標、高手 |
| **合計** | **58** | | **6,200** | |

- 商店全部商品（店面背景 4,400＋打擊音效 7,200＋寵物 17,500）合計 **29,100** 遊戲幣（含稀有寵物 5 隻 12,500、限定打擊音效 2 款 3,300）；成就獎勵約佔 21%，其餘由日常遊玩賺取。
- 遊玩獎勵（`js/config.js` 的 `COIN_REWARD`，結算時由 `CoinShop.reward` 發放）：基本 = 評價（特上 40／上 30／並 22／見習 14／修行 6）＋本局星級 × 3；每首歌第一次拿到「並」以上 +50（不分難度）；每首每個難度第一次全連擊 +20。
- `COIN_SHOP = true`（已開放）：購買前會跳確認框；成就解鎖就發遊戲幣。
- 屋台等級（`js/config.js` 的 `STALL`、`js/shop.js` 的 `Stall`）：每場結算得經驗值（評價 15/12/9/7/5＋難度 0/1/3），Lv.1～20（Lv.20 約 340 場）。商店商品依 `lv` 逐級開放（開放只是「可以買」，還是要花遊戲幣）；稀有寵物、限定音效改用 `req` 特殊條件（過關 8-bit 歌曲、連續 7 天開攤、10 首特上、困難全連擊）。舊存檔依累計場數補算經驗（每場 10）。

## 2. 計算規則

| 用語 | 定義 |
|---|---|
| 完成一場 | 一局打到結算畫面（中途回主選單不算）。新手教學不算 |
| 首 | 不同的歌，同一首不同難度只算 1 首；未特別註明時任一難度都算 |
| 評價 | 結算的 5 級：特上 ＞ 上 ＞ 並 ＞ 見習 ＞ 修行（`js/config.js` 的 `RATINGS`） |
| FC（全連擊） | 該場沒有 BAD（`R.fc`） |
| AG（全 GREAT） | 該場全部 GREAT（`R.ag`） |
| 廣島燒 | 湊齊四種食材合成的一份（`s.oko`） |
| 音感等級 | 節奏分析的等級（`js/rhythm.js` 的 `LEVELS`），依最近的遊玩紀錄判定 |
| 隱藏 | 未解鎖前只顯示「？？？」和提示，不顯示條件 |

參考：每局音符數（實測各曲平均）簡單 81（44～126）、普通 145（83～215）、困難 188（133～252）；所以連擊門檻最高定在 200（只有困難的部分曲子做得到）。

## 4. 實作備註

- **判定時機**：大部分在結算時檢查（`js/rhythm.js` 記錄 totals 的地方之後）；新手教學、自動校正、分享、語言切換、商店裝備在各自的動作當下檢查。
- **需要新增的存檔欄位**：`achievements`（已解鎖的 ID 與時間）、`playDays`（`streak_7` 用的遊玩日期）、`langsUsed`（`polyglot`）、`songDiffs`（`all_diffs`：每首完成過哪些難度）、`coinsPaid`（已發過獎勵的成就，`COIN_SHOP` 開啟時補發用）。
- **已有的資料可直接用**：`totals`（場數、廣島燒、最高連擊、每首遊玩次數）、`medals`（每首每難度的最佳評價、FC、AG）、`Rhythm.analyze()`（音感等級）。
- **舊玩家**：上線時用既有的 `totals`、`medals` 回溯判定，已達成的直接解鎖（不跳通知，只在成就畫面標「新」）。
- **解鎖通知**：結算畫面或當下右上角跳出小卡片（成就名稱＋等級色＋獎勵）。
- **多語系**：名稱與條件文字要在 `js/i18n.js` 補日文、英文。
- **上架平台**：Steam 成就、Game Center、Google Play 成就需另外登錄；ID 直接沿用本表（隱藏成就對應平台的「隱藏」設定）。
